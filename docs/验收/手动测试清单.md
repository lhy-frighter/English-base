# 手动测试清单（v2.28.0）

> 启动应用后按顺序点即可。前四组约 30 分钟；第五组重型封板可选。
> 发现任何不对：截图 + 说明在第几步，按 P0/P1 修。

## 第一组：跟读台（#112，约 10 分钟）

- [ ] **闸门① 调度提示**：侧栏「跟读」→ 文本框有英文句（没有就自己粘贴一句）→「● 开始跟读」→ 读完整句 →「停止并比对」→ 出现绿色提示"已记入明天再练"。
  - 顺带：点比对结果里的红/黄词 → 听到自己录音里**该词的切片**；词旁 🔈 → 听到模型读单个词。
- [ ] **闸门② 续练卡**：正常次日才到期；想立即测，先运行 `node spike-v5/test-shadow-due-now.cjs`，再回「今日」→ 出现「跟读续练 · N 句到期」卡 → 点入 → 逐句"下一句续练"/"这句不用再练" → 走完显示"今日续练完成 🎉"。
- [ ] **闸门③ 断点保留**：跟读台输入半句（不用录）→ 直接关窗口 → 重开进跟读台 → 半句还在。

## 第二组：阅读 + 词库（约 10 分钟）

- [ ] **同根词可点击（v2.25.1）**：「词库」→ 点一个已学词（如 issue）→ 详情下方同根/近义词（issued、issues）→ 点词弹释义面板、小喇叭能发音。
- [ ] **功能词不建卡**：查 the / of 等 → 面板显示"功能词随用随会，不建卡"，无加入复习按钮。
- [ ] **阅读链路**：「阅读」→ 书库打开一篇素材 → 点生词弹面板 → 划选英文句子 → 浮动条点跟读 → 跳到跟读台且句子已带入；划选**中文**不应被送入。
- [ ] **漏网词回收**：「今日」点「漏网词回收」（或词库页头入口）→ 页头有返回键 → 勾选几个词 → 批量加入 → 去「复习」能看到新卡。

## 第三组：S12 能力测评（约 10 分钟）

- [ ] 「今日」点「能力测评」（或仪表盘能力区按钮）→ 选 B2 → 开始。
- [ ] 阅读时点 2–3 个词、翻译 1 段（翻译模型需已安装）→ 顶部"查词/机翻"计数相应增长。
- [ ] 「我读完了，去答题」→ 答 4 题 → 提交 → 看到总分 + 四项拆解（理解/覆盖/速度/少依赖）。
- [ ] 去「仪表盘」能力区 → 确认出现本次得分记录。
- [ ] 再开一次同一等级测评 → 确认抽到的是**另一篇**文本（不会重复）。

## 第四组：文案目视（#113，2 分钟）

- [ ] 「语音」页：标题/区块为"语音模型管理"；状态显示"已安装/未完成/未下载"；多线程那行是人话。
- [ ] 「好文」页：文章标签显示"刚好适合"；说明文字为"最佳学习区间（稍有挑战、基本能读懂）"。

## 第五组：断点续学与今日（5 分钟）

- [ ] 阅读一篇文章并向下滚动几段 → 关应用 → 重开（落在今日页）→ 点主按钮"继续…"→ 回到刚才那一段。
- [ ] 今日页顶部只有一个主按钮，其他入口在下方卡片。

## 第六组：重型封板闸门（可选，约 40 分钟）

- [ ] **ASR 30 分钟连续转写**：跟读/语音页连续用 30 分钟 → 不卡死、转写正常、内存不持续增长。
- [ ] **ASR↔翻译内存互斥**：跟读一次 → 阅读里翻译几段 → 再回跟读 → 旧引擎退出、内存回落（可看任务管理器）。
- [ ] **TTS 手感**：跟读示范音有自然停顿（pauses 版），以耳听为准。
