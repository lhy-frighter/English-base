## 1. 核心设计：一个画像，四个机制

### 1.1 一个画像

所有模块只读写同一个学习者画像（V9 资产层 + 既有事实表）：

- 资产：word / chunk / grammar / pronunciation / concept
- 证据：asset_evidence（结果口径见 §1.3）
- 调度：cards + FSRS（review_log）
- 相遇：asset_encounters（reading / conversation / shadow / exam / syllabus）
- 派生优先级：**有界加性分**（见 §1.3.4），查询时现算、带算法版本，不物化。

任何模块不得再自建一套"掌握状态"。

### 1.2 四个机制

1. **相遇即记录（不是证据）**：任何模块遇到资产，自动追加 `asset_encounters`——阅读重现、对话听到、跟读练到、考试出现。**相遇只证明"接触过"，绝不证明掌握**；多看几次文章不会推高能力。
2. **行为才出证据**：只有产生可观察的学习行为才写 `asset_evidence`（答对、主动表达、完成改写、跟读改善并经人工确认、考试正确运用、练习观察）。
3. **弱点即调度信号**：priority 同时喂给每日好文选材、对话引导（system prompt 注入）、今日页唯一下一步；只影响优先级，永不硬锁内容。
4. **会话自动复盘（Debrief）**：读完一篇、聊完一场、跟完一组、考完一套，自动生成可持久化、可恢复的"本次收获"草稿，批量确认、零表单。

### 1.3 证据口径（v1.1 重点修订）

#### 1.3.1 asset_evidence 结果枚举（扩展，migration v15 重建表）

| result | 含义 | 典型来源 |
|---|---|---|
| `recognized` | 只完成识别/理解（听辨卡答对、阅读中理解确认） | review / reading |
| `correct` | 答题正确 | exam / review |
| `partial` | 部分正确 | exam / review |
| `wrong` | 答错 | exam / review |
| `practice_observation` | 一次练习观察（如单词重录被识别通过），**不等于掌握、不等于同意建资产** | shadow / conversation |
| `improved` | 此前问题点经练习确认改善（**仅对已存在资产**追加） | shadow / conversation |
| `recurred` | 问题再次出现，自动提权 | 多来源 |
| `used_spontaneously` | **无任何提示**，自然主动使用（最高权重） | conversation |
| `used_prompted` | AI 或卡片明确要求后使用（含「再用一次」、被引导对话） | conversation |
| `used_after_correction` | 被纠正后立即重说 | conversation |

> 关键区分：**系统自己提示用户、再把结果记成 spontaneous = 指标自我刷高，严禁。**

#### 1.3.2 用出检测的匹配要求（不能只做字符串包含）

- 单词边界匹配（禁止 art 命中 party）；屈折/词形还原（复用 ruleLemma/lemmaOf）；
- chunk 规范化变体匹配（normalizeExpression + 变体表）；引号、标点、contractions 归一；
- 中英混说句只评估英文片段；
- AI 当轮明确提示/练习链路中的使用 → `used_prompted` / `used_after_correction`，不计 spontaneous；
- 每资产每会话同类证据至多一条（idempotency_key 幂等）；
- **grammar 不做自由对话字符串包含识别**：首版语法证据只在明确练习（grammar 卡）或纠错（TEACH/纠正链路）中写。

#### 1.3.3 来源定位精确到轮次

对话来源的 `origin_ref` 必须存 **conversation_turns 的 id**（不是只存 session key），并在 locator/payload 中同时保存：

- session_key（上级范围）、turn_id、消息字符范围、committed_text_hash、原句快照；
- 点回来源直达具体气泡；某轮删除/重生成时按 turn_id 精确墓碑化。

阅读来源沿用 text_id + 段落/字符定位；考试来源 paper_id + q_index。

#### 1.3.4 priority：有界加性分（替代连乘）

```text
priority(algo v1) =
    overdue_score          // 逾期程度，归一到 [0,3]
  + recurrence_score       // 复发/遗忘次数，封顶 [0,3]
  + recent_error_score     // 近 7 天错误，封顶 [0,2]
  + exam_weight            // 等级/考纲权重，[0,1]
  + output_gap_score       // 输出型弱点（只会认不会用），[0,1]
  - recent_success_decay   // 近期成功衰减，[0,2]
```

- 每项归一到固定区间，总分有上下限，不存在"一项为零整体消失"或极端值放大；
- 保存算法版本（`priority_algo` 字段/设置），今日页可展示"为什么推荐它"。

## 2. S13-0：语音轮次自动收束（v1.1 新增，最高优先级）

**要解决的问题**：当前 `onSpeechEnd`（ConversationPage，VAD 回调）一触发就转写并发送——Silero VAD 只懂"安静了多久"，句中思考停顿会被当成一轮结束（误切）；单纯调大 redemptionMs 只会增加延迟，无法判断句子是否完整。

### 2.1 技术选型：Smart Turn v3 + 现有 Silero VAD + Whisper

- **Silero VAD**：判断"正在说话 / 暂时安静"（已随包，#135）；
- **Smart Turn v3（ONNX）**：判断"这次停顿是句中思考，还是一轮真正结束"——直接分析原始波形（Whisper-Tiny encoder 主干 + 浅层线性头，8M 参数，int8 ONNX 约 **8MB**，**BSD-2-Clause**），不依赖先转写；VAD 检出安静后才运行；官方建议输入当前轮次末尾最多 8 秒，用户继续说则用更新后的轮次重判 ["https://huggingface.co/pipecat-ai/smart-turn-v3"]。
- **Whisper Base**：判定轮次结束后，只对完整轮次转写一次；
- 多语言（审查称支持中英文）——**模型卡未明确列语言，spike 必须实测中文/中英混说**，不提前承诺。
- 无 Python / `.node` / sidecar：用现有 onnxruntime-web 在独立 Worker 内推理，符合架构铁律；模型 8MB 走随包 vendor（同 VAD 模式：vendor/smart-turn/ + NOTICE + manifest bytes/sha256，vite 拷贝）。

```text
连续麦克风 PCM
   → Silero VAD（语音/候选停顿 350–500ms）
   → TurnAssembler（累计完整用户轮次）
   → Smart Turn ONNX（取轮次末尾 ≤8s 重判）
       ├─ 未说完 → 继续收音（用户重新开口则取消待提交）
       └─ 已说完 → Whisper Base 完整转写一次 → 发送对话模型
```

### 2.2 S13-0a：Smart Turn 限时 spike（不接生产）

- 30–50 条本机冻结录音，覆盖：句中思考停顿、um/uh、中英混说、短回答、长句、多句一整轮、背景噪声；
- 重点指标（不是普通准确率）：
  ①提前抢话率；②真说完后等待 p50/p95；③一轮被错拆成几段的比例；④空白/噪声误提交率；⑤每轮 Whisper 调用次数（目标=1）；⑥与现有 barge-in 是否冲突；
- 记录 Worker 冷启动、CPU/内存、连续 30 分钟稳定性；不达标则降级保留手动/固定 VAD 方案。

### 2.3 S13-0b：TurnAssembler + 自动提交状态机

- VAD 候选停顿 350–500ms → Smart Turn 判定；
- 判结束 → 立即提交（Whisper 一次）；判未结束 → 继续收音；
- **最大等待 2.5s** 兜底提交，防止悬而不决；用户重新开口 → 取消待提交计时；
- 保留「立即发送」按钮作人工兜底；单轮硬上限 60s；
- 替换现有 `onSpeechEnd → 直接转写发送` 路径；与 barge-in（AI 播放中开口）协同：barge-in 优先，轮次收束只作用于用户空闲发言阶段。

**DoD**：冻结集指标达标（抢话率/错拆率/spike 定阈值）；多句一整轮可自然说完不被截断；重复触发幂等；全量测试通过。

## 3. 其余任务切片

### S13-a：跟读 inline drill + 自动复盘 + 反向视图

**A. 跟读台发音 UX 改版**

- 问题词点击改为**就地小卡片（inline popover）**，不再串弹层：
  - 模型音 / 我的录音两个播放键（复用切片播放）；
  - 系统**建议问题 tag**：疑似替换→音素、漏词→弱读、卡顿 pill→节奏；一键可改；
  - 主按钮「🎙 再读这个词」：录单词 → 即时复判，通过显示 ✓；
  - 次按钮「存入复习」：用当前 tag 一键建发音资产（听辨+产出卡），零表单；
  - 「详细编辑」才打开 AssetCaptureSheet。
- **口径修正（v1.1）**：
  - 重录练习先写 `practice_observation`；界面用「**文本匹配度**」「**本次识别通过**」，禁用"准确度/达标/发音正确"等措辞（Whisper 只判是否识别成目标词，不证明音素正确）；
  - **练习≠同意建资产**：未点「存入复习」不创建 pronunciation 资产；仅当资产已存在时，通过后追加 `improved` 证据。
- 句级展示：**文本匹配度 / 完整度 / 流利度**（对齐数据现算），不做音素级宣称。

**B. 自动复盘（Debrief）+ 草稿持久化（migration v15 新表）**

```sql
CREATE TABLE debrief_drafts(
  draft_key TEXT PRIMARY KEY,
  origin_kind TEXT NOT NULL CHECK(origin_kind IN ('reading','conversation','shadow','exam')),
  origin_ref TEXT NOT NULL,
  candidates_json TEXT NOT NULL DEFAULT '[]' CHECK(json_valid(candidates_json)),
  status TEXT NOT NULL DEFAULT 'open' CHECK(status IN ('open','done','skipped')),
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  UNIQUE(origin_kind, origin_ref)
);
```

- 读完/聊完/考完自动生成候选（新增词/表达/语法/发音点，默认全选）；关闭窗口/崩溃/跳转后草稿保留，可从今日页继续处理；
- 确认后批量走 captureAsset（已存在只追加相遇）；缺必填字段的 grammar/pronunciation 保留为候选，不静默建资产；
- 跳过只关提醒，不删事实相遇/证据。

**C. 来源反向视图（已学地图）**

- 文章顶部：已学 X 词、Y 表达、Z 句已跟读通过，可点进资产；
- 对话结束页：本场沉淀清单（资产 + 用出证据，区分 spontaneous/prompted）。

### S13-b：用出证据 + 复习卡「再用一次」

- 用户轮发送时按 §1.3.2 检测并分类写证据（`used_spontaneously` / `used_prompted` / `used_after_correction`）；中文轮、TEACH 教学轮不计；
- 复习卡背面展示"你在 N 场对话中自然用过 / M 次被引导使用"；
- 「再用一次」：word/chunk/grammar 卡 → 跳对话带引导指令，AI 引导用出至少一来回 → 写 **`used_prompted`**（不是 spontaneous），卡片标记"已输出练习"。

### S13-c：弱点跨模块调度

- **好文选材**："严格覆盖率 + CEFR"基础上，按 priority 提升弱点资产复现权重，推荐理由明示；
- **对话引导**：会话开始注入近期 pron/grammar 弱点（AI 刻意使用、引导说出）；该链路产生的用出一律 `used_prompted`；可在设置关闭；
- **今日页调度器**：唯一下一步综合 到期复习（含逾期）+ 断点位置 + 高 priority 弱点 + 测评差距，主按钮 + 次级入口；展示推荐理由（priority 明细）。

### S13-d：跟读达标回写 + 考试错题跨域

- **migration v15**：shadow_sentences 加 `origin_kind`（reading/conversation）、`origin_ref`（对话存 turn_id）；
- 跟读句达标（相似度 + 1/3/7 通过）→ shadow_sentences 置通过、来源句标「✓ 已跟读通过」（文章按 sentence_hash 匹配；对话按 turn_id 标记）；
- **考试错题跨域**：听力错题「🎙 送跟读台精听」；语法/词汇错题「💬 开对话演练」（带考点，演练证据 `used_prompted`）；考后复盘生成"薄弱能力清单"排进今日页。

## 6. 封板闸门（S13 整体）

1. 四模块（阅读/对话/跟读/考试）信号全部汇入同一画像，无模块私有掌握状态；
2. 相遇只进 encounters；能力结论只由行为证据支撑（抽查：多次"相遇"不产生能力分）；
3. 用出证据三分类正确：无提示=spontaneous、被引导=prompted、纠正后=after_correction；抽查无自我刷高；
4. 会话复盘有持久化草稿，批量写入幂等（重复确认零新增）；
5. 弱点跨模块复现/引导生效但不硬锁；priority 明细可解释；
6. 资产可点回精确来源（对话直达 turn），来源删除保留墓碑快照；
7. 仪表盘区分"投入（分钟/次数）"与"能力（证据/测评趋势）"，成卡数不是能力指标；
8. migration v15 自动备份、可重入、失败整体回滚；全量测试全绿。
