# V0 验证工具包 · 记录模板

> 配套《英语学习产品方案-v1.6-开工定稿.md》第 22 节。**期间不写任何产品代码**。每日记录 5 分钟，摩擦随时记。**一周后**汇总成《V0 验证报告》，四条 Go 门槛全过才开工。

## 0. Go 门槛（数字前置承诺，开工前写死在这里）

- [ ] 门槛 1：工具割裂导致每周损失 **≥60 分钟**（默认阈值，如要修改必须写入报告并给理由）
- [ ] 门槛 2：至少 **1 次**摩擦直接导致学习中断或放弃
- [ ] 门槛 3：手工标注预演——可解析 token 未命中率 **≤5%**，且义项判定 **≤15 秒/词**
- [ ] 门槛 4：一周结束时，明知要投入开发，**仍强烈想解决**
