# 英语底座·网页送读（浏览器扩展）

把当前英文网页正文一键发送到本地桌面应用「个人英语能力底座」的书库，对应产品方案 V4「URL 抓取导入 → 浏览器扩展」。

## 工作方式

- 在目标网页点扩展图标 →「发送本页正文到底座」
- 扩展在**页面内**用 DOM 算法抽取正文（article/main 优先、去导航/脚本/广告、段落密度过滤，与桌面端 `app-electron/url-extract.cjs` 同策略）
- 通过 `http://127.0.0.1:47823/ingest` 只发到**本机**运行的桌面应用（loopback，不经过任何外部服务器）
- 兜底：扩展也支持「复制正文 Markdown」「下载 .md」（桌面应用没开时可用）

## 安装（开发者模式加载，免构建）

1. 打开 Chrome/Edge 的扩展页：`chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `browser-extension`
4. 保持桌面应用运行，打开任意英文网页 → 点工具栏扩展图标 → 发送

## 边界与后续

- 只支持 http/https 普通网页；chrome://、扩展商店页等无法注入
- 强 JS 渲染的单页应用（内容靠滚动动态加载）需要先等正文渲染完再点
- 桌面端接收服务仅绑 127.0.0.1、请求体 ≤2MB、正文 <100 字拒收；端口占用时自动跳过且不影响应用
- 当前为**原生 MV3 零构建**实现（刻意不引 WXT 工具链，方案 §23 中"扩展本身"是可砍项）；后续若要多浏览器打包、content script 自动注入/右键菜单/options 页，再迁移 WXT
