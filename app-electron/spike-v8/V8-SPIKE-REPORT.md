# V8-1 WebLLM 真机 Spike 报告

- 日期：2026-09-23
- 目的：在真实 Electron + 本机硬件上验证「本地大脑跑实时对话」的可行性，为 ADR-6 补齐证据，裁决：
  1. 本地模型档位（Qwen2.5 1.5B vs 3B）
  2. 模型缓存权威源（模型商店 vs WebLLM 自带缓存）
  3. 打断、SRI、上下文边界等工程约束
- 环境：Electron 38.8.6 / Chromium 140；@mlc-ai/web-llm 0.2.85（Apache-2.0，手工 vendor）；
  GPU：AMD RDNA 2（WebGPU adapter 正常识别）；网络：广州，huggingface.co 直连不稳定。
- **V8-1 结论：工程可行性通过（不是全部闸门封板）。** 已锁定：文字默认 3B、模型商店单一缓存权威、上下文 token 预算滑窗+摘要。
  未决（登记为 V8-3 阻断验收项）：语音档位、打断→静音/重新可录实测、LLM＋ASR/TTS 共存内存与 RSS 回落。

## 一、过程中踩坑与架构含义（均已解决）

| # | 现象 | 结论 / 处置 |
|---|---|---|
| 1 | hf-mirror.com 直连被 CORS 拦截（无 `Access-Control-Allow-Origin`） | 渲染进程不能直连镜像。新增主进程代理：`app://app/__webllm__/hf/...`、`/__webllm__/lib/...`，由主进程 Node fetch 上游并流式回传（COEP/CORP 齐全）。**生产形态同理：模型获取必须经主进程（模型商店），渲染 Worker 只拿本地/同源 URL。** |
| 2 | WebLLM Cache API 后端报 `Request scheme 'app' is unsupported` | 浏览器 Cache API 仅接受 http(s) scheme，无法缓存 app:// 产物。改用 **IndexedDB 缓存后端**（scheme 无关，缓存落在 userData = 工程 `data/webllm-profile`，满足"全部文件在工程目录"）。 |
| 3 | 连续对话约 10 轮后模型输出退化为固定模板 "You might need to learn about X"，纠错/追问全部失效 | 根因=**上下文长度**：prebuilt wasm 为 `cs1k`（约 1024 token，v0_2_84/base 目录下 Qwen2.5 1.5B/3B 仅有 cs1k 变体，无更长上下文 lib）。隔离测试：短回复连续 8 轮全部健康；全新历史复测 1.5B 6/10、3B 8/10。**产品必须做 token 预算滑动窗口 + 早期摘要，不能按固定轮数粗切、不能无限累积。** |

## 二、1.5B（Qwen2.5-1.5B-Instruct-q4f32_1-MLC）实测数据

- 冷加载（含约 780MB 下载，30 个 shard）：235s；二次启动走 IndexedDB 缓存，秒级。
- 时延（20 个场景，流式）：
  - 首 token：p50 **1289ms**，p95 8538ms（首轮含 shader 编译，属冷启动）
  - 整轮（≤256 token）：p50 **5221ms**，p95 10960ms
- 教学质量（两个独立口径，不混用）：
  - **累积历史口径**（20 场景顺序对话，含前序对话的示范效应，不能单独当独立场景准确率）：**11/20**
  - **全新历史口径**（每场景独立会话）：**6/10**——语法纠错 5/6（interesting→interested 1 次未纠正）；雅思式追问 **1/4**，1.5B 倾向复述/附和学习者的话（echo），不主动提问
- 打断：旧版测量口径有误（把人为等待的 700ms 计入），1.5B 的三段打断计时留 V8-3 真机测。
- SRI：错误 config 哈希 + `onFailure:'error'`，CreateMLCEngine 如期抛错（**fail-deny PASS**）。

### 1.5B 小结
文本闲聊、语法纠错基本可用；**弱项是主动追问/话题推进（雅思场景）与长上下文**。首 token ~1.3s 对文字可接受，也是未来语音模式的低延迟候选。

## 三、3B（Qwen2.5-3B-Instruct-q4f32_1-MLC）实测数据

- 权重 62 个 shard 共 **1.66GB**；冷加载（含下载）401s（约 6.7min），二次启动走缓存秒级。
- 显存需求：vram_required_MB **2894**（RDNA2 实测可跑）。
- 时延（20 场景，流式）：
  - 首 token：p50 **2633ms**，p95 12145ms（首轮含 shader 编译；稳态约 2.5–2.8s）
  - 整轮：p50 **10534ms**，p95 21359ms（3B 输出更长，≤256 token）
- 教学质量（两个独立口径，不混用）：
  - **累积历史口径**（20 场景顺序对话，含前序对话的示范效应）：**20/20**——1.5B 在第 11 轮起因上下文压力退化，3B 同条件下保持稳定
  - **全新历史口径**（每场景独立会话）：**8/10**——语法纠错 4/6（2 次为随机性未命中，输出中其实已含正确讨论）；雅思追问 **4/4**
  - 短回复连续 8 轮：全部健康
- 打断（三段独立计时，长故事生成 700ms 后调用 `interruptGenerate()`，partial=4 字符）：
  - ① 调用 → Promise 返回（callResolveMs）：**0ms**
  - ② 调用 → 生成迭代器完全结束（iterEndMs）：**9472ms**
  - ③ 打断后 → 下一请求首 token 返回（nextUsableMs）：**18793ms**（其中首 token 生成 10093ms，含重新预热）
  - 注意：迭代器收尾近 9.5s，对语音 UX 是真实风险；1.5B 同项与语音侧「打断→静音/可录」留 V8-3 真机裁决。
- SRI fail-deny PASS。

## 四、对 ADR-6 六条件的证据映射

1. 云端不自动兜底：spike 全程无云端调用；主进程代理仅获取公开模型文件。云端开关/safeStorage 在 V8-2 接线。
2. 延迟五段实测：①松键→转写（V8-3 语音链测）；②确认文本→首 token（1.5B p50 1289ms / 3B p50 2633ms）；③确认文本→首音（V8-3 测）；④打断→静音（3B 调用本身 0ms 返回，但迭代器收尾 9.5s；静音与可录必须 V8-3 真机测，当前不宣称 <500ms）；⑤打断→重新可录（V8-3 测）。
3. 已播文本按播放游标：打断 API 可用，partial 可在生成端原子冻结；播放端游标在 V8-3 实现。
4. 推理租约（**V8-3 阻断验收项**）：本次仅验证 LLM 单独可跑；LLM 与 ASR/TTS/翻译的互斥/共存 RSS 未测（两份日志 mainRSS_KB 均 undefined）。已有 coordinator 三租约，需加 LLM 租约并真机验证"LLM 会话常驻、ASR/TTS 按轮切换、RSS 回落"。
5. 缓存单一权威：**裁决建议=模型商店为唯一权威**（见下）。
6. 轮次状态机/幂等键：migration v13 已落库；打断/失败路径在 V8-2 起按状态机接线。

## 五、裁决与闸门状态

- **缓存权威：方案 A——模型商店为唯一权威（锁定）。** 证据：①渲染进程直连镜像有 CORS，必须经主进程；②Cache API 不支持 app scheme；模型商店本就具备固定版本/哈希/镜像/原子安装/回滚，WebLLM 仅作为推理引擎，其 IndexedDB 缓存视为运行时缓存（可删除、可重建），不承载"可信版本"语义。工程落地：模型商店逐文件下载 config、tokenizer、wasm lib、全部权重 shard 并逐一校验，主进程以同源 URL serve；SRI/哈希失败即拒绝。
- **上下文：token 预算滑动窗口 + 早期摘要（锁定方向）。** 摘要只作提示上下文，不是学习事实源；近期原始轮次、已确认纠错和成卡证据不能被摘要覆盖；窗口按 token 预算计算并为输出预留空间，不按固定轮数粗切。
- **模型档位裁决：**
  - **文字对话默认 3B**：两口径质量均领先（累积 20/20 vs 11/20；全新 8/10 vs 6/10），雅思追问 4/4 vs 1/4，抗上下文压力显著更强；稳态首 token 2.6s 对文字可接受（流式可见进度）。
  - **1.5B 为低延迟/低配档与语音候选**（780MB、首 token 1.3s、显存更友好）；配合 few-shot prompt 弥补追问弱项。
  - 两档均为 Apache-2.0（WebLLM 引擎 + Qwen2.5 权重），许可证干净。
- **延迟对语音链的预判（V8-3 实测确认）**：3B 首 token 2.6s + ASR + TTS，端到端首音可能 4–5s，语音场景优先 1.5B 或采用句子级流式（边生成边送 TTS）。
- **未决闸门（V8-3 阻断验收，不得提前宣称封板）**：
  1. 语音档位真机裁决（1.5B vs 3B vs 句子级流式）；
  2. 打断→静音、打断→重新可录的五段延迟实测；3B 迭代器收尾 9.5s 问题需在语音链复测；
  3. LLM＋ASR/TTS/翻译共存内存与 RSS 回落（含 LLM 会话常驻、ASR/TTS 按轮切换）；
  4. 断网冷启动只加载已通过模型商店校验的版本；manifest revision 变化强制失效旧 IndexedDB、删除模型同步清缓存（#121 DoD）。
