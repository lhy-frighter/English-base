# V0 手工标注预演 · 技术测量报告

> Go 门槛 3 的测量数据（对应方案 v1.6 §22.3）。测量日期：2026-09-12。测量工具：`preannotate.py`（一次性测量脚本，非产品代码）。结论先行：**可解析 token 未命中率 0.05%，远低于 5% 门槛——ECDICT 词库覆盖不是瓶颈**；真正的设计风险在**MWE 短语质量**与**专名判定**两处，已量化。

## 1. 测量方法

按方案 §7.2 的管线顺序模拟：分词（UAX#29 近似）→ 多词表达最长匹配（n≤5）→ 专名识别 → 数字/符号单列 → lemma 变体归并（ECDICT exchange 字段 + lemma.en.txt）→ 未命中分类。义项候选数以 ECDICT `translation` 字段的释义行数近似。

- 词典：ECDICT 完整版 `ecdict.csv`（401,818 个单词词条 + 360,137 个多词词条）+ `lemma.en.txt`（84,487 组）
- 文本：3 篇 × 约 600 词，难度梯度对齐方案的三类场景（来源均为 GitHub 可直连、许可清晰）：

| 文本 | 难度对标 | 来源 |
|---|---|---|
| textA_news | 六级阅读（新闻/叙事） | Brown 语料库 press reportage（ca01+ca02） |
| textB_essay | 外刊/评论（文学化随笔） | Gutenberg：Chesterton《The Ball and The Cross》开篇 |
| textC_academic | 论文节选（学术文体） | Brown 语料库 learned（cj01+cj02，射电天文主题） |

- 唯一未命中：`transpirating`（学术文本，词典无此形，属生造/罕见变形）。

## 3. 三个设计级发现（比未命中率更重要）

### 3.1 ECDICT 收录大量专名词条 → 专名判定不能依赖"不在词典"

句中大写且**在词典里**的 token（cap_word）：textA **38 个**（6.6%）、textB 15、textC 14。例子：Fulton、Atlanta、Georgia 等人名地名都在 ECDICT 里。
**影响**：若按"词典有→普通词"处理，专名会被计入词汇量与覆盖率，known% 虚高。**V1 管线顺序必须是专名启发式先于词条映射**（方案 §7.2 已如此设计，本测量确认了必要性），且专名判定规则建议：句中大写 + lemma 不在 BNC 高频前 1 万词 → 专名候选；仅靠"不在词典"不够。

### 3.2 ECDICT 的 36 万条 MWE 不可直接使用 → 必须过滤

MWE 命中中"垃圾短语"（内容词 <2，如纯功能词组合）占比：news **53%**、essay **80%**、academic **31%**。典型垃圾命中：`to be`、`All the`、`that many`、`like that`、`the world`、`there is`、`have been`。有效命中例子：`Grand Jury`、`Superior Court`、`flying machine`、`radio emission`、`thermal conductivity of the surface`。
**影响**：直接套用会造成"点词点出 the City"式垃圾词条。**V1 的 MWE 词表需要质量过滤**——候选规则：短语须含 ≥2 个非功能词内容词，或改用筛选后的搭配表（V2 搭配库）；本测量脚本的过滤规则可直接移植为初版实现。

### 3.3 义项判定负担可控（待人工计时确认）

多义词（释义行数 ≥4）占已匹配词比例低（每篇 26–30 个位置、去重后更少），候选义项数普遍 4–6 行（注意：translation 行数含"词组/网络"行，实际义项数更少）。样本已存 `results/preannotate_results.json` 的 `polysemy_sample` 字段。
**待人工完成**：从样本中抽 20 个词，实际计时"读义项候选→选定义项"的耗时（门槛 ≤15 秒/词）——见第 5 节用户待办。

## 4. MWE 缺口清单

三篇文本中**未发现**"连续未命中构成的短语缺口"（gaps 均为空）——即没有出现"两个词各自认识、合起来是词典漏收短语"的情况。MWE 缺口风险初步评级：低（样本量 1840 token，统计力有限，V1 后继续用未命中分类监控）。
